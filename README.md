# 미적분Ⅰ 수업용 웹페이지

2022 개정 교육과정 〈미적분Ⅰ〉 진도에 맞춘 수업용 단일 웹페이지입니다.
브라우저에서 **`index.html`** 을 열면 바로 사용할 수 있습니다. (인터넷 연결 없이 동작)

## 구성
- **좌측 사이드바**: 대단원 → 중단원 → 소단원 구조로, 각 소단원에 **차시(진도)** 와 **단원명** 을 표시합니다. (총 64차시)
- **소단원별 본문**
  1. **교과서 개념 정리** — 제공된 교과서 원문에서 개념·설명을 추출(대단원 Ⅰ). 대단원 Ⅱ·Ⅲ은 교과서 원문이 없어 2022 개정 교육과정 표준 개념으로 요약 정리.
  2. **예제** — 교과서 예제와 풀이(접었다 펼치기).
  3. **EBS 올림푸스 문제** — 부교재 EBS 올림푸스 미적분Ⅰ(2022 개정) 문항을 진도(강)에 맞춰 제시. 교재 쪽수·문항코드 표시, 정답·해설 토글.

## 자료 출처
- 교과서 원문(대단원 Ⅰ: 함수의 극한과 연속) 및 EBS 올림푸스 미적분Ⅰ 문항 332개는 제공된 HWP 파일에서 추출했습니다.
- 수식은 한글(HWP) 수식 개체를 LaTeX로 변환하여 **MathJax**(`mathjax-tex-svg.js`, 로컬 번들)로 렌더링합니다.
- 문제·해설 속 그래프는 원본 이미지에서 추출하여 삽입했습니다.

## 파일
- `index.html` — 웹페이지 본체(데이터·스타일·스크립트 포함, 단일 파일)
- `mathjax-tex-svg.js` — 오프라인 수식 렌더링용 MathJax(로컬)
